# 🔐 Data Encryption Awareness Tool

An interactive Python GUI project designed to teach users the fundamentals of data encryption and cybersecurity awareness.

## ✨ Features

- 🔐 Interactive encryption/decryption demonstration
- 🛡️ Cybersecurity awareness tips
- 🎯 Interactive encryption quiz
- 📚 Simple explanation of plaintext, ciphertext, encryption and decryption
- 🌙 Professional dark cybersecurity-themed interface
- 🔑 Fernet symmetric encryption
- 🖥️ Built with Python and Tkinter

## 🛠️ Technologies

- Python 3
- Tkinter
- Cryptography / Fernet

## 🚀 Installation

Install the required package:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python encryption_awareness_tool.py
```
